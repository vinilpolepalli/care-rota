# Care Rota

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Cova (YC S26) works in. Not affiliated with or endorsed by Cova.

Day board for a fictional home care agency: synthetic visits, caregivers and clients. Attention rules (LATE RISK, GAP, UNCOVERED) use fixed visible thresholds and are illustrations, not a care-management product. Stats are computed from the sample data.

Static export of a Next.js app. Built with Claude Code.
